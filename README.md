# 黯水晶的个人主页

我的第一个网页项目，用原生 HTML + CSS 手写。

🔗 **在线预览**：https://anshuijingli-boop.github.io/MyFirstWebsite/

## 特性

- 圆形头像 + 三张卡片布局
- 响应式：窄屏自动变成单列
- 深色模式：跟随系统设置自动切换

## 技术栈

- HTML5
- CSS3（Grid / Flexbox / 媒体查询）
- GitHub Pages 部署
